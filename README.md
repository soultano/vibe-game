# Pixel Dominion

Пиксельная стратегия на карте Земли. Один игрок и соперники под управлением игры; мир и прогресс сохраняются в браузере.

## Локальный запуск

Требуется Node.js. Установка зависимостей не нужна.

```sh
npm start
```

Откройте http://127.0.0.1:4173. Для другого порта: `PORT=4300 npm start`.

## Игровой цикл

Выберите имя, фракцию и свободную клетку суши. База захватывает соседние клетки, получает энергию и развивается. Улучшайте базу, выбирайте политику расширения или обороны, выполняйте задания и соперничайте за территорию. Валюта за задания используется внутри игры; реальных покупок нет.

Клавиша пробела приостанавливает время, кнопки масштаба приближают карту. Для перемещения карты используйте перетаскивание. Управление также доступно экранными кнопками.

## Проверка

```sh
npm test
```

Исходники интерфейса и игрового движка находятся в `dist/`. Статический сервер использует только стандартные библиотеки Node.js. Игра не обращается к внешним API во время партии.

## География

Географическая основа: Natural Earth, public domain, административные границы масштаба 1:110m. Карта преобразована в сетку 360 × 180, Антарктида исключена из игровых территорий. Воспроизводимый генератор: `scripts/generate-world.py`.

Источник: https://www.naturalearthdata.com/about/terms-of-use/

## Объём этой версии

Это законченная локальная одиночная версия с ИИ-соперниками. Общий серверный мир, сетевые аккаунты, реальные платежи и нагрузка в 50 000 игроков в неё не входят.
