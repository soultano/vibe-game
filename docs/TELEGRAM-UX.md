# Упрощение интерфейса и устранение задержек

Главный экран содержит «База», «Отряды», «Ещё», ресурсы, профиль и три кнопки камеры. Награды, сектор, рейтинг, достижения, друзья, магазин, способности и настройки находятся внутри «Ещё». У отдельного отряда три основных команды; дополнительные раскрываются отдельно. Во время выбора цели командная панель сворачивается до инструкции и отмены, освобождая карту. После основания базы обучение больше не открывается самопроизвольно. Достижения дают одно короткое уведомление вместо нескольких баннеров и циклов частиц.

У панелей, профиля, обучения и нативных диалогов общий менеджер. Открытие следующего экрана закрывает предыдущий. Закрытие и Telegram Back возвращают к карте. Медленная загрузка магазина не открывает его снова после закрытия; при ошибке есть повтор. Прокрутка внутри окна отделена от жестов карты.

## Куда можно направить бойца

Выберите отряд → «Идти», «Атаковать» или «Захватить» → нажмите гекс. Доступные цели движения зелёные, территория противника красная, доступный захват золотой. Серые гексы недоступны. Наведение мышью или нажатие объясняет воду, защитный щит, дальность, лимит территории, блокировку или отсутствие общей границы. Ошибка сохраняет режим выбора и не отправляет заведомо недопустимый запрос. Авиация не захватывает землю. В общем виде карты выбор команды приближает отряд.

Подсветка показывает предварительно допустимые цели по текущему снимку мира. Окончательный приказ и проходимый маршрут проверяет сервер: обстановка может измениться, а обход может отсутствовать. Показан подтверждённый маршрут до восьми ближайших шагов и самостоятельная метка конечной цели. Непосчитанный участок не выдаётся за прямой проходимый путь. Команды работают через общий авторизованный API сайта и Mini App.

## Причины задержек и исправления

| Причина | Изменение |
|---|---|
| Выбор бойца, открытие меню и обновление NPC инвалидировали всю землю | Раздельные флаги обновления текстур/владения и экранных элементов. Неизменные тайлы и снимки бойцов переиспользуют карту. |
| Каждый шаг перетаскивания строил подробный ландшафт | Сохранённый кадр перемещается/масштабируется; подробности обновляются не чаще одного раза в 180 мс. После отпускания рисуется точный кадр. Глобус использует собственную проекцию. |
| WebGL-кадр каждый раз копировался в Canvas2D | На карте используется самостоятельный GPU-слой и небольшой 2D HUD без чтения полного GPU-кадра. Копирование оставлено для явного просмотра модели 512×512 и адаптеров без DOM. |
| Карта анимировалась за окнами и в неактивной Mini App | Анимация карты приостанавливается; отдельный просмотр модели продолжает свою анимацию. При возврате карта обновляется. Серверный мир продолжает развиваться. |
| Данные маски Земли дважды попадали в статическую сборку | Унифицирован JSON-импорт. Отрисовка Кланхолла вынесена в модуль, загружаемый при появлении цитадели на экране. Все изменения другого разработчика сохранены. |
| Возможное выделение целей по всей карте каждый кадр | Не более 192 видимых кандидатов и кэш полигонов между кадрами. Поиска маршрута на наведении нет. |

## Жесты Telegram

Клиент вызывает `disableVerticalSwipes()` при наличии API версии 7.7+, использует `touch-action:none` и отменяет нативный scroll только на карте. Высота обновляется по стабильному состоянию viewport. Back закрывает текущий экран. Повторная и поздняя загрузка SDK поддерживаются; сайт без SDK сохраняет все игровые возможности.

Контракт: [официальная документация Telegram Mini Apps](https://core.telegram.org/bots/webapps). Нативные кнопки закрытия и жесты самого заголовка Telegram остаются под управлением Telegram. Старые клиенты без соответствующего API не могут гарантировать отключение сворачивания контейнера.

## Проверка

- Настоящий клиент выполняется через Node-адаптер DOM/Canvas и настоящий API; одинаковые сценарии проходят без Telegram, с данными запуска без SDK и с SDK-адаптером. Проверяются вход, общий аккаунт/прогресс, меню, выбор бойца, приказ, способности, улучшение и выход.
- Последовательности «отряд → база → меню → награды → магазин → достижения → профиль → обучение → Кланхолл» оставляют одно окно. Проверяются Back, поздний ответ магазина, ошибка/повтор и выключение Mini App.
- Счётчики подтверждают отсутствие перерисовки земли при выборе бойца, открытии панелей и обновлении неизменного владения. За 30 кадров жеста допускаются до трёх перестроений, затем один финальный кадр. Это проверка объёма работы, а не измерение FPS телефона.
- Проверяются отказы для щитов/воды/дальности/лимита/границы, настоящий HTTP-приказ после окончания щита, захват, серверный урон, маршруты, сохранение команд и защита сессий.
- Отдельный адаптер Three.js подтверждает отсутствие копирования GPU→Canvas2D при отрисовке карты, скелетные анимации, ограниченные загрузки, очистку и обработку потери WebGL-контекста.
- `npm test`, `npm run check:client`, `npm run build`, `npm run check:worker` проверяют клиент, сервер, SQL, сборку и настоящий Node HTTP с перезапуском процесса. Бюджеты загрузки не увеличены.

Браузер, headless-браузер и физический Telegram не запускались. CSS-компоновка и реальные жесты/FPS на конкретном телефоне инструментально не измерялись. Подтверждения опубликованной сборки и численные результаты сохраняются отдельно в `outputs/telegram-ux/` рабочего пространства.
