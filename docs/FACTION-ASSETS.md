# Модели баз и эмблемы

19 октября 2026 года для всех пяти фракций созданы текстурированные 3D-штабы через Meshy по предоставленным `base_<id>_4k.png` из папки `01node (main building)`. Новые эмблемы отдельно перегенерированы встроенным ImageGen по `emblem_<id>_4k.png`: прозрачный фон, без надписей и плашек, читаемый центральный символ. Исходные пользовательские изображения не изменялись.

## Генерация Meshy

Использован `meshy-cli@0.4.0`, ресурс `image-to-3d`: smart topology, целевые 4000 треугольников, текстурирование и PBR включены, исходные текстуры 2K, формат GLB. На каждую фракцию выполнено одно платное задание, без повторной генерации, отдельного retexture или remesh. Фактически списано **75 Meshy credits**, по 15 за модель.

## Подготовка для игры

`scripts/prepare-headquarters.mjs` обрабатывает уже скачанные результаты локально. Исходная геометрия и UV сохранены; нулевые нормали восстановлены по геометрии, остальные нормализованы. MikkTSpace-тангенты записаны в GLB с сохранением UV-швов. Цветовые и normal maps уменьшены до 1024 px, metallic/roughness до 512 px. Внешние декодеры и ссылки на текстуры не требуются.

Пять GLB занимают 3 339 768 байт вместо исходных 38 643 740 байт. Превью `*-poster.webp` и резервные спрайты получены из рендеров этих заданий Meshy. PNG эмблем находятся в `src/client/assets/factions/`; сборка выпускает WebP 192 px, а спрайты штабов — WebP 384 px. Все десять файлов интерфейса вместе занимают около 195 КБ. Актуальные промпты эмблем — [`faction-logo-prompts.json`](faction-logo-prompts.json). `headquarters-prompts.json` относится к прежним 2D-спрайтам, заменённым этими моделями.

## Подключение

Один общий WebGL2 renderer обслуживает окно осмотра, выбор штаба и карту. Каждая фракция загружается и декодируется один раз. На карте отображается прозрачный кэшированный Canvas-ракурс из GLB; вращение в окне меняет саму модель. Постоянного цикла 3D-анимации нет: кадры рисуются при загрузке, взаимодействии и возвращении вкладки в активное состояние. Three.js вынесен в отдельный динамический chunk.

Осмотр доступен в справочнике фракций, при выборе базы и на панели своего штаба. Работают перетаскивание, кнопки вращения, стрелки клавиатуры и Home. При отсутствии WebGL2, ошибке загрузки или потере контекста остаётся изображение. После сетевой ошибки автоматические перерисовки карты не запускают новые скачивания; повторная попытка доступна при новом открытии осмотра.

## Проверка без браузера

- `npm test`: валидатор Khronos для всех GLB (ноль ошибок и предупреждений), PBR-текстуры, бюджет, SHA-256, нормализация и освобождение ресурсов; дедупликация загрузок, повтор после ошибки, поздние ответы, фоновый режим, вращение, быстрая смена фракции и потеря контекста через адаптер renderer; клиентский fallback без WebGL.
- `npm run build && npm run check:worker`: встроенные GLB/постеры, MIME, ETag/304, размер загрузок, динамический chunk и реальный HTTP/SQLite поток.
- `npm run check:client`: вход, постановка базы, способности, строительство, награды, восстановление связи и выход.

Рендеры Meshy и эмблемы просмотрены как локальные изображения, включая эмблемы в размерах 32/48/80 px. По просьбе пользователя браузер не запускался; реальный GPU/WebGL в браузере этим прогоном не проверялся.
